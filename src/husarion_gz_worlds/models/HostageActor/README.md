# HostageActor

This model vendors the Gazebo Fuel walking actor mesh used by the hostage
scenario templates.

- Source: `https://fuel.gazebosim.org/1.0/Mingfei/models/actor`
- Upstream owner: Mingfei
- Upstream license: Creative Commons Attribution 4.0 International
  (`http://creativecommons.org/licenses/by/4.0/`)
- Vendored file: `meshes/walk.dae`
- Use: copy the actor block from `scenarios/hostage_actor_snippet.sdf` into a
  scenario world and keep the `HostageActorController` plugin enabled.
